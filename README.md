# Quest Box

Квест-устройство «обезвредь бомбу» на Arduino Mega 2560 по мотивам игры Keep Talking and Nobody Explodes: один игрок работает с устройством, эксперты ведут его по руководству.

## Прошивки

| Папка | Что это |
|---|---|
| `firmware/QuestBox4/` | Полная версия. Сценарии выбираются кодом доступа, модули: провода, эхо, кнопка, морзе, символы, пароль, шифр. Код `0000` — режим проверки железа. |
| `firmware/QuestBoxICT/` | Упрощённая версия для ICT Week: 3 случайных модуля из 5, 4 минуты, 3 ошибки — взрыв. Лучшее время хранится в EEPROM. |
| `firmware/legacy_v1/` | Первая версия (5 последовательных модулей и сейф) и тест датчиков. Описание — в `docs/v1/`. |

Ответы на модули печатаются в Serial (9600) для ведущего. Удержание `D` три секунды — сброс в меню.

## Железо

- Arduino Mega 2560
- LCD 16×2 I2C (адрес 0x27)
- 4-разрядный 7-сегментный индикатор
- клавиатура 4×4
- 5 кнопок и 5 светодиодов
- 6 проводов-разъёмов
- микрофон (аналоговый вход A15), пассивный зуммер

Номера пинов — в начале каждого скетча, блок «ПОДКЛЮЧЕНИЕ».

## Сборка

1. Arduino IDE, плата **Arduino Mega or Mega 2560**.
2. Библиотеки: **LiquidCrystal I2C**, **Keypad**.
3. Открыть нужный `.ino` из `firmware/` и залить.

## Документация

- `docs/v1/` — описание, карта пинов и заметки первой версии.
- Руководство по обезвреживанию для экспертов и ведущего ведётся отдельно (узбекский, русский, английский).
