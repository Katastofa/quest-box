# Quest Box — Документация

## Игровая логика

### Поток состояний

```
[START] → gameState=0
    │
    ▼
[Модуль 1: SIMON]
  Нажать BTN1 → BTN2 → BTN3 → BTN4 по порядку
  Успех → выдаётся цифра кода "1" → gameState=1
    │
    ▼
[Модуль 2: SOUND]
  Звуковой датчик A15 >= 500
  Успех → выдаётся цифра кода "3" → gameState=2
    │
    ▼
[Модуль 3: LED]
  BTN5 нажать только когда горит LED4 (переключаются каждые 600 мс)
  Ошибка (нажал в LED5) → −25 сек
  Успех → выдаётся цифра кода "5" → gameState=3
    │
    ▼
[Модуль 4: SAPPER]
  Мини-таймер 30 сек
  Вытащить: ЖЁЛТЫЙ (D43) → КРАСНЫЙ (D45) → СИНИЙ (D47)
  Запрещённые: D44, D46, D48 → ускорение таймера
  Жёлтый провод намеренно делит оставшееся время ÷2
  Успех → выдаётся цифра кода "7" → gameState=4
    │
    ▼
[Модуль 5: SAFE]
  Ввести "1357" на клавиатуре + нажать #
  Ошибка → −30 сек, повтор ввода
  * = очистить введённый код
  Таймаут 30 сек → −20 сек, повтор
  Успех → "BOMB DEFUSED!"
    │
    ▼
[WIN] — экран победы, игра остановлена
```

---

### Таймер игры

- Старт: **180 секунд**
- Отображается на 7-segment в формате **MM:SS**
- Мультиплекс обновляется каждые ~800 мкс вызовом `update7Segment()`
- При `timeLeft = 0` → экран "TIME'S UP!", бесконечный цикл
- `loseTime(n)` вычитает n секунд, минимум 0

### Механика Sapper подробно

```
Таймер сапёра: 30 000 мс
Ошибка (запрещённый или не тот провод):
  remaining = remaining * 3/4  (ускорение)
  loseTime(25)                 (штраф из главного таймера)

Жёлтый провод (первый правильный):
  remaining = remaining / 2   (намеренная ловушка!)

После взрыва: 10 сек ожидания, затем перезапуск Sapper
```

## Известные проблемы и TODO

| Проблема | Описание | Решение |
|----------|----------|---------|
| Debug-читы в коде | Клавиши C/D — пропуск и рестарт | Убрать перед публичным показом |
| Мусорный текст на LCD | Некоторые строки с артефактами кодировки | Почистить все `lcd.print()` |
| HC-SR04 не используется | Датчик подключён, логика не написана | Добавить модуль или отключить |
| `showCode1357AndPause()` закомментирована | Код не показывается игроку явно | Раскомментировать или удалить |
| Servo импортирован, не используется | Зарезервировано для будущего | — |
