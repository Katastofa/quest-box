## Полная карта пинов

### LCD I2C

| Пин Arduino | Подключение |
|-------------|-------------|
| D20 (SDA) | LCD SDA |
| D21 (SCL) | LCD SCL |
| 5V | LCD VCC |
| GND | LCD GND |

### 4-digit 7-Segment (ручной мультиплекс)

| Пин Arduino | Назначение |
|-------------|------------|
| D2 | Сегмент A |
| D3 | Сегмент B |
| D4 | Сегмент C |
| D5 | Сегмент D |
| D6 | Сегмент E |
| D7 | Сегмент F |
| D8 | Сегмент G |
| D9 | Сегмент DP (точка) |
| D10 | Разряд 1 (активный LOW) |
| D11 | Разряд 2 |
| D12 | Разряд 3 |
| D13 | Разряд 4 |
| A0 | Бузер 7-seg (buzzerSeg) |

> Логика разрядов — активный LOW: `digitalWrite(digitPin, LOW)` включает разряд.

### Клавиатура 4×4

| Тип | Arduino пины |
|-----|-------------|
| Строки (ROW) | D22, D23, D24, D25 |
| Столбцы (COL) | D26, D27, D28, D29 |

### Модуль Simon (кнопки + LED)

| Элемент | Пин | Режим |
|---------|-----|-------|
| BTN1 | D30 | INPUT |
| LED1 | D31 | OUTPUT |
| BTN2 | D32 | INPUT |
| LED2 | D33 | OUTPUT |
| BTN3 | D34 | INPUT |
| LED3 | D35 | OUTPUT |
| BTN4 | D36 | INPUT |
| LED4 | D37 | OUTPUT |
| BTN5 | D42 | INPUT |
| LED5 | D39 | OUTPUT |
| Бузер Simon | D49 | OUTPUT (buzzer2) |

### Датчик звука

| Пин | Подключение |
|-----|-------------|
| A15 | KY-038 аналоговый выход |

> Порог срабатывания: `analogRead(A15) >= 500`

### Модуль Sapper (провода-пазл)

| Пин | Назначение | Роль |
|-----|------------|------|
| D43 | YELLOW | Рабочий, шаг 1 |
| D44 | FORBIDDEN1 | Запрещённый |
| D45 | RED | Рабочий, шаг 2 |
| D46 | FORBIDDEN2 | Запрещённый |
| D47 | BLUE | Рабочий, шаг 3 |
| D48 | FORBIDDEN3 | Запрещённый |

> Все провода на `INPUT_PULLUP`. Состояние HIGH = провод вытащен (разрыв подтяжки).  
> Правильный порядок: YELLOW (43) → RED (45) → BLUE (47).

### Ультразвук HC-SR04

| Пин | Подключение |
|-----|-------------|
| D40 | TRIG |
| D41 | ECHO |

> Подключён, но в текущей версии игры не задействован.

---

## Схема питания

- Arduino Mega от USB или 9V DC Jack
- LCD, бузеры, датчик звука — от 5V Arduino
- LED — через резисторы 220 Ом на GND
