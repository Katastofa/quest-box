# Robotics Lab — Quest Box / Bomb Game

## Описание

Интерактивная квест-игра на Arduino Mega. Игрок проходит **5 последовательных модулей**, собирая цифры секретного кода. Финальная задача — ввести код `1357` на клавиатуре до истечения таймера.

Используется как реквизит квест-комнаты или демо-стенд лаборатории.

## Механика игры

Общее время: **3 минуты (180 секунд)**, отображается на 4-digit 7-segment дисплее.

| Шаг | Модуль | Задача | Штраф за ошибку |
|-----|--------|--------|-----------------|
| 1 | **Simon** | Нажать BTN1 → BTN2 → BTN3 → BTN4 по порядку | −25 сек |
| 2 | **Sound** | Создать громкий звук (хлопок, крик) — порог аналога ≥ 500 | — |
| 3 | **LED** | Нажать BTN5 только пока горит LED4 (не LED5) | −25 сек |
| 4 | **Sapper** | Вытащить ЖЁЛТЫЙ → КРАСНЫЙ → СИНИЙ, не трогая запрещённые | ускорение мини-таймера |
| 5 | **Safe** | Ввести код `1357` на клавиатуре и нажать `#` | −30 сек |

Цифры кода (1, 3, 5, 7) выдаются последовательно при прохождении модулей 1–4.

## Аппаратная часть

| Компонент | Модель | Назначение |
|-----------|--------|------------|
| Микроконтроллер | Arduino Mega | Основное управление |
| Дисплей | LCD 16×2 I2C (0x27) | Вывод состояния игры |
| Индикатор таймера | 4-digit 7-segment (Common Cathode) | Обратный отсчёт |
| Ввод | Клавиатура 4×4 | Ввод кода сейфа |
| Кнопки | 5× тактовые кнопки | Модули Simon и LED |
| Светодиоды | 5× LED | Подсветка Simon и LED-модуля |
| Датчик звука | KY-038 (аналог) | Модуль Sound |
| Провода-пазл | 6 проводов с разъёмами | Модуль Sapper |
| Зуммеры | 2× пассивный бузер | Звуковые эффекты |

Подробная карта пинов — см. [hardware/README.md](hardware/README.md).

## Запуск

1. Открой `code/quest_game/quest_game.ino` в Arduino IDE
2. Установи библиотеки: `LiquidCrystal_I2C`, `Keypad`
3. Board: **Arduino Mega or Mega 2560**, Port: COMx
4. Залей скетч, открой Serial Monitor (9600 baud)

### Debug-читы (убрать перед показом)

| Клавиша | Действие |
|---------|----------|
| `C` | Пропустить текущий модуль |
| `D` | Перезапустить игру |
